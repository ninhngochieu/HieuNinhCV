## Solution-Architecture note (lens 2)
Frontend-only + `output:'export'` + nginx:alpine on :3000 is the **correct, minimal** architecture for static content — no Node runtime, CDN-ready, tiny attack surface. Single-page, no client routing/state → appropriately simple. No architectural concerns.

## Key Findings (with evidence)
- **F1 (Medium, Contrast):** bio body text `#94a3b8` on `#020617` ≈ 5.3:1 — passes AA for large but marginal for 16px body. Bump to `#cbd5e1` (~9:1).
- **F2 (Medium, Contrast/Slop):** section dividers use `--glass-border` (rgba 0.08) — nearly invisible, fails as separator. Use a brighter line.
- **F3 (Medium, Microcopy):** bio summary is generic AI filler. Rewrite to specific, first-person, metric-light.
- **F4 (Medium, Motion a11y):** floating blobs ignore `prefers-reduced-motion`. Add opt-out.
- **F5 (Slop, POV):** entire visual language is the default "dark developer portfolio" — nothing personal. Acceptable for a functional CV; flag if differentiation matters.

## Quick Wins (<30 min each)
1. Brighten `--secondary` body text → `#cbd5e1` (F1).
2. Section dividers → `var(--secondary)` at low opacity instead of near-invisible border (F2).
3. Add `@media (prefers-reduced-motion: reduce)` to disable blob float (F4).
4. Rewrite `bio.summary` to non-generic copy (F3) — content, user-ownable.
