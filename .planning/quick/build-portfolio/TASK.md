# Quick Task: Portfolio with Next.js, ASP.NET Core, Scalar, and PocketBase

## Objective
Build a professional portfolio showcase that connects a Next.js frontend to an ASP.NET Core Web API, which in turn interacts with a PocketBase backend. The API should be documented using Scalar.

## Success Criteria
- [ ] PocketBase integrated into .NET Aspire (Container).
- [ ] ASP.NET Core API has Scalar documentation enabled.
- [ ] ASP.NET Core API has endpoints for Portfolio data (Projects, Bio, Contact).
- [ ] Next.js frontend displays Portfolio data with premium aesthetics.
- [ ] All components communicate successfully.

## Architecture
- **Frontend**: Next.js 15 (React 19)
- **API**: ASP.NET Core 10.0 + Scalar
- **Database**: PocketBase (Port 8090)
- **Orchestration**: .NET Aspire 13.x (SDK)
