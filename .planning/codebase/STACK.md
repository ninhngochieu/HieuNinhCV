# Technology Stack

## Frontend
- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS (globals.css, page.module.css)
- **Package Manager**: npm

## Backend
- **Framework**: [ASP.NET Core](https://dotnet.microsoft.com/en-us/apps/aspnet) (.NET 10 Preview)
- **API**: Minimal APIs
- **Service Discovery**: Microsoft.Extensions.ServiceDiscovery
- **Documentation**: [Scalar](https://scalar.com/) (OpenAPI)
- **Observability**: [OpenTelemetry](https://opentelemetry.io/)

## Orchestration
- **Platform**: [.NET Aspire](https://dotnet.microsoft.com/en-us/apps/aspire)
- **Host**: HieuNinhCV.AppHost (Distributed Application)

## Infrastructure / Data
- **Auth & Database**: [PocketBase](https://pocketbase.io/) (used via API calls)
- **Containerization**: Docker (for PocketBase)
